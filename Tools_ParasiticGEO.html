PARASITIC GEOMETRY

Procedural generation for environments and real time VFX
This project is a combination of multiple different tools and systems that have been developed over the past 6 months, including the procedural building generator and procedural mold systems also available in this portfolio retrofitted and optimized into Unreal Engine HDAs, a series of damage shaders intended to give the buildings and environment a worn down and grungy appearance, as well as a series of spline tools fully developed in unreal.
The final result is displayed in a large city-scape playable environment, with all the resulting baked elements from the different tools optimized for game use and real-time rendering.

How it works

Mold tool refactor:
The mold VFX system had to be refactored to make it optimal for large-scale environment use. Instead of using a single large volume to generate the mold, the system was changed to use multiple smaller volumes that can be placed in the scene and generate mold in a more localized manner. This allows for better control over the distribution of the mold and reduces the overall computational load on the system, as well as making it susceptible to frustum culling and occlusion culling, this wasn't possible with the previous system due to the large extent of the final generated volume.

Building toolrefactor:
The building generator tool stayed mostly identical to the original version, with the exception of some minor parameters intended to make the tool usable for large-scale levels. These changes mostly pertain to the introduction of data-tables that allow the user to define the series of rules, patterns and floor distribution inside static memory. This was done to avoid having to manually type the instruction rules for each building, which would be very time consuming and prone to typing errors.
The other major change was the introduction of manual controls for the temp module dimensions, this removes the necessity for having an extra mesh stored in memory solely for the purpose of reading data. Instead, the user can now define the module dimensions directly in the tool parameters.
