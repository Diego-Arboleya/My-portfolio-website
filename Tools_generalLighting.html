GENERAL LIGHTING
TOOL

The idea behind this project was to research and develop a tool based on a necessity or issue we found in unreal engine.
As a lighting artist, one of my biggest pet peeves when lighting a scene is having to select and configure each lighting source individually, navigating panels of parameters I rarely even modify. Thus, the general lighting tool was born. It allows the user to batch selected light sources by type in each scene, so that each group of lights can be selected afterwards and be modified in conjunction from the widget panel, which contains the main parameters usually used to set up the lighting but with the posibility to easily add or remove parameters to the tool.
The tool was developed using C++ to create custom functions for the getting and setting of parameters, light batching, etc. With the main logic connecting these functions having been done in blueprints.
The tool will soon be available on FAB as a downloadable plugin.

How it works

The tool is divided into 2 main pieces: the control widget and the light hub.
The hub is placed in the level where the lighting is going to be set up, it is the element in charge of storing the different groups of lights that are going to be accessed by the widget along with the group name.
The main controler logic is housed in the widget. From here the user can create the different light groups separated by type, select which group is going to be modified and also which lights are going to be refreshed.
The reason behind giving the user control over which lights are getting refreshed is to avoid performance bottlenecks, as it is only necessary to refresh the proprties of the light group that is getting modified. If we were to remove this option and have all the lights be refreshed constantly, the tool would become unusable as the GPU would get backed up by trying to refresh every single light in the scene the moment one property is modified.
The logic for this widget is set up in two stages. On one hand, the tool's utility functions have been created using C++ and stored in a blueprint function library, and then the actual code execution flow and logic have been set up using blueprints
